# 🧮 BMI App

A simple BMI calculator made with Python Tkinter

## ⚙️ Technologies

- Python
- Tkinter

# 📔 What does it do?

**BMI App** is a simple desktop application that calculates a person's **Body Mass Index (BMI)** using their height and weight.

The app provides:

* 📏 Height input
* ⚖️ Weight input
* 🧮 BMI calculation
* 📊 BMI result

# 📚 What I Learned

While building this project, I learned:

* Python GUI development with Tkinter
* Taking user input
* Working with mathematical formulas
* Connecting UI elements with Python logic
* Building a simple desktop application
